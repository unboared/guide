## Format

| | |
|---|---|
| **Duration** | 1h to 1h30 |
| **Games used** | Gloofy Pop, Bomber Kitten |
| **Audience** | Younger crowd, competition lovers |
| **Ideal for** | Late-night events, gaming nights |

## Recommended schedule

| Timing | Activity |
|--------|----------|
| **0-5 min** | Connection and explanation |
| **5-25 min** | Gloofy Pop (multiple rounds) |
| **25-40 min** | Break (15 min) |
| **40-60 min** | Bomber Kitten (tournament) |
| **60-75 min** | Break (15 min) |
| **75-90 min** | Final: top players from each game face off |

## Managing large groups (Bomber Kitten)

Bomber Kitten is limited to 20 players. If you have more participants:

1. **Form groups** of 10-15 players
2. Each group plays a round
3. The **winners from each group** meet in the final
4. The tournament format builds natural suspense and keeps everyone involved

<Callout type="tip">
Arcade Night is perfect for closing out an evening on a high. The energy and competition create an electric atmosphere. Turn up the volume and commentate the eliminations live!
</Callout>
