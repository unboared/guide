## Sound issues

### Sound doesn't start

Modern browsers block automatic audio until there has been an interaction with the page. **Click once** anywhere on the game page to enable sound.

### Blind Test sound stops working

After several consecutive games, music may stop playing even though the game continues visually.

**Solution:** Close and restart your browser (not just the tab, but the entire browser). Players will need to rescan the QR code.

### Volume is too low

Check multiple volume levels:
1. The **browser volume** (right-click on the tab)
2. The **computer volume**
3. The **TV volume** (if sound goes through HDMI)
4. The **external speaker volume** (if you're using one)

<Callout type="tip">
For the Blind Test, an external speaker is strongly recommended. The built-in computer or TV speakers are rarely loud enough for a bar setting.
</Callout>

## Display issues

### Screen is cropped or poorly proportioned

Switch to **full screen** mode (F11 on Windows, Fn+F on Mac). Unboared's display is optimized for full screen mode.

### Image doesn't show on the TV

Check:
1. The **HDMI cable** is properly plugged in on both ends
2. The TV is on the **correct input** (HDMI 1, HDMI 2...)
3. The computer display is set to **mirror** or **extend** mode

On Windows: `Windows + P` > Duplicate
On Mac: System Settings > Displays > Mirror Display

### QR code is too small to scan

Use the **QR Code button** in the control panel (bottom right) to display the QR code full screen.
