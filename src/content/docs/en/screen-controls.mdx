## The control panel

At the bottom right of the main screen, a control panel gives you access to essential commands.

![The control panel at the bottom of the screen](/images/screenshots/04_settings-buttons-panel.png)

## Available commands

| Button | Function |
|--------|----------|
| **Menu** (house icon) | Return to the game selection screen. Players stay connected: no need to rescan. The current game stops. |
| **Pause / Resume** | Pause the game or resume it. Useful for making an announcement or handling an unexpected situation. In the Blind Test, pause stops the timer but not the music: mute the sound too if needed. When you control the night from your phone, this button moves to the remote. |
| **QR Code** | Display the QR code full screen. The game is automatically paused. Close it to resume. |

The three-line button (☰), to the right of the others, holds the rest:

| Button | Function |
|--------|----------|
| **Full Screen** | Enter or exit full screen mode. Same as pressing F11. |
| **Mute** | Mute or unmute the game sound. Useful when making an announcement on the microphone. |
| **Delete scores** | Permanently delete this game's scores for your venue (you'll be asked to confirm). |

## When to use what

### Display the QR code full screen

Use this when you want to **invite new players** to join. The QR code is displayed across the entire screen, making it easier to scan from a distance.

The game is automatically paused when the QR code is shown, and resumes when you close it.

![QR code displayed full screen](/images/screenshots/05_big-qr-code.png)

### Pause the game

Pausing is useful for:
- Making an **announcement** to the audience
- Handling an **unexpected** technical issue
- Giving players time to **reconnect**

### Mute the sound

Useful when:
- You're picking up the **microphone** for an announcement
- The game audio is interrupting an important conversation
- You're taking a **music break** between two games

## The remote on your phone

You can run the night from your own phone, without going back to the computer. On the TV menu, the **"Run it from your phone"** card (or, once the card is closed, the **"Control from your phone"** badge) shows a QR code: scan it with your phone.

From the remote, you can:
- **Pick or change the game**, then start or stop it
- **Pause** and **mute** the sound
- **Show the players' QR code** full screen on the TV
- See **how many players are connected**
- Adjust the game's settings (for example the Blind Test playlist or the quiz control room)

<Callout type="tip">
Take a few minutes to familiarize yourself with these controls before your first event. It will save you from fumbling during the action.
</Callout>
