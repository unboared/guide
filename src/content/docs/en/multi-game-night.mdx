title: Multi-Game Night
description: Chain multiple game types for a varied and dynamic evening.
---

## Format

| | |
|---|---|
| **Duration** | 1h30 to 2h |
| **Games used** | GeoLoc, Unblind Test, Bomber Kitten, P'tit Bac |
| **Audience** | All audiences |
| **Ideal for** | Varied nights, discovering Unboared |

## Recommended schedule

The ideal format: **15 minutes of play + 15 minutes of break**, on repeat.

| Timing | Activity |
|--------|----------|
| **0-15 min** | GeoLoc (3 rounds, 3 winners) |
| **15-30 min** | Break |
| **30-45 min** | Unblind Test (15 songs) |
| **45-60 min** | Break |
| **60-75 min** | Bomber Kitten (tournament if 20+ players) |
| **75-90 min** | Break |
| **90-105 min** | P'tit Bac (3 rounds) |
| **105-120 min** | Final leaderboard + winners' tournament (bonus) |

## The winners' tournament (bonus)

At the end of the night, invite the winner from each game to face off in an ultimate challenge. Pick a fast-paced game (GeoLoc or Bomber Kitten) for a spectacular finale.

<Callout type="tip">
This format is perfect for your first Unboared night: it introduces all game types to your audience and helps you identify which ones work best at your venue.
</Callout>
