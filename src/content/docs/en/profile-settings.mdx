title: Edit my profile
description: Change your name, email, password, and display language.
---

## Access your settings

Go to [console.unboared.com/account](https://console.unboared.com/account) to access your profile settings.

## Editable information

| Setting | How to change it |
|---------|-----------------|
| **First name / Last name** | Edit directly in the fields and click Save |
| **Email** | Change the address and confirm with your current password |
| **Password** | Click "Reset password" to receive a password reset email |

## Change the screen language

The display language of the console (the screen on the TV) is configured from your account page. You can choose between **French** and **English**.

<Callout type="info">
This setting changes the language of the console interface (main screen) and the games. Each host can have their own language preference.
</Callout>

## Change the dashboard language

In the dashboard ([b2b.unboared.com](https://b2b.unboared.com)), go to **Settings** > **Profile** to switch the language between French and English.
