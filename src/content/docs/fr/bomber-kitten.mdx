## En bref

| | |
|---|---|
| **Catégorie** | Action |
| **Joueurs** | 2 à 20 |
| **Durée** | ~5 minutes par manche |
| **Personnalisable** | Non |

## Le principe

Chaque joueur contrôle un personnage dans une arène vue de dessus. Le but : poser des bombes pour éliminer les autres joueurs tout en évitant les explosions. Le dernier survivant gagne la manche.

Les joueurs se déplacent et posent des bombes depuis leur téléphone grâce à un joystick virtuel et un bouton d'action.

![Interface joueur sur téléphone — Bomber Kitten](/images/screenshots/08c_player-phone-gamepad-bomber-kitten.jpg)

## Déroulement d'une partie

### Lancement

Le jeu se lance directement dès que les joueurs sont connectés. Pas de configuration nécessaire.

### Pendant le jeu

1. Chaque joueur apparaît dans l'arène avec son avatar
2. Les joueurs se déplacent avec le joystick sur leur téléphone
3. Ils posent des bombes avec le bouton d'action
4. Les bombes explosent en croix après quelques secondes
5. Les joueurs éliminés deviennent spectateurs
6. Le dernier survivant remporte la manche

### Fin de partie

Le classement s'affiche en fonction du nombre de manches gagnées et des éliminations.

## Conseils d'animation

**Au lancement :**
"C'est Bomber Kitten ! Vous contrôlez un personnage, vous posez des bombes et vous essayez de survivre. Le joystick pour bouger, le bouton pour poser une bombe. Le dernier en vie gagne !"

**Pendant le jeu :**
- Commentez les éliminations en direct : "Oh, double élimination !"
- Encouragez les duels finaux : "Plus que deux ! Qui va craquer en premier ?"
- Signalez les power-ups quand ils apparaissent

**Avec plus de 20 joueurs :**
Bomber Kitten est limité à 20 joueurs simultanés. Si vous avez plus de participants, organisez des tournois par groupes : les gagnants de chaque groupe s'affrontent en finale.

<Callout type="tip">
Bomber Kitten est parfait pour finir une soirée en beauté. L'aspect compétitif et visuel crée beaucoup d'énergie dans la salle.
</Callout>
