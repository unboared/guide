## Les métriques principales

Sur votre tableau de bord, vous retrouvez les indicateurs clés de votre activité :

### Nombre de joueurs
Le nombre total de joueurs qui ont scanné le QR code et joué sur la période sélectionnée. C'est votre indicateur principal d'engagement.

### Temps par joueur
La durée moyenne de jeu par joueur. Un temps élevé (> 5 minutes) indique un bon engagement.

### Temps d'utilisation
Le temps total pendant lequel votre installation Unboared a été active.

## Filtrer vos données

Utilisez le sélecteur de dates en haut de la page pour afficher les statistiques sur une période spécifique :
- Aujourd'hui
- Les 7 derniers jours
- Les 30 derniers jours
- Les 3 derniers mois
- Les 12 derniers mois

## Les graphiques

Le dashboard vous propose plusieurs visualisations :
- **Évolution des joueurs** : courbe montrant le nombre de joueurs sur la période
- **Répartition par jeu** : quel pourcentage de temps est passé sur chaque jeu
- **Joueurs simultanés** : pic de joueurs en même temps

<Callout type="tip">
Surveillez la répartition par jeu pour identifier les favoris de votre public. Cela vous aidera à mieux choisir les jeux pour vos prochaines soirées.
</Callout>
