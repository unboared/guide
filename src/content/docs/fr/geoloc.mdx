## En bref

| | |
|---|---|
| **Catégorie** | Quiz & Culture |
| **Joueurs** | Illimité |
| **Durée** | ~5 minutes |
| **Personnalisable** | Oui (nombre de villes, thème) |

## Le principe

Une ville s'affiche à l'écran. Les joueurs doivent placer un curseur sur la carte de leur téléphone pour indiquer où elle se trouve. Plus le curseur est proche de la bonne position, plus le joueur marque de points.

## Déroulement d'une partie

### Configuration

Avant de lancer, vous pouvez ajuster :
- Le **nombre de villes** à deviner
- Le **thème géographique** (France, Europe, Monde...)

### Pendant le jeu

1. Le nom d'une ville s'affiche sur la TV
2. Chaque joueur place son curseur sur la carte de son téléphone
3. Un compte à rebours laisse le temps de réfléchir
4. La bonne réponse s'affiche avec les distances de chaque joueur
5. Les points sont attribués selon la précision

### Fin de partie

Le classement final s'affiche. Les meilleurs scores sont automatiquement enregistrés dans les records de votre établissement.

## Conseils d'animation

**Au lancement :**
"On va tester votre sens de l'orientation ! Une ville va s'afficher et vous devez la placer sur la carte. Plus vous êtes proche, plus vous marquez de points."

**Pendant le jeu :**
- Commentez les réponses surprenantes : "Oh, quelqu'un a placé Paris en Belgique !"
- Félicitez les bons résultats : "Incroyable, à seulement 12 km !"
- Entretenez le suspense entre chaque manche

**En cas d'égalité :**
Proposez une manche supplémentaire en duel entre les ex-aequo.

<Callout type="tip">
GeoLoc est le jeu idéal pour commencer une soirée. Il est accessible à tous, ne nécessite aucune connaissance spécifique et crée immédiatement de l'interaction.
</Callout>
