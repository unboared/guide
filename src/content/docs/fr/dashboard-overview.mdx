## Accéder au dashboard

Le dashboard est accessible à l'adresse **[b2b.unboared.com](https://b2b.unboared.com)**. Connectez-vous avec le même compte que celui utilisé sur la console.

![Le tableau de bord Unboared](/images/screenshots/06_dashboard-static-page.png)

## Les sections du dashboard

Le menu de gauche vous donne accès aux différentes sections :

| Section | Description |
|---------|-------------|
| **Tableau de bord** | Vue globale de vos statistiques : nombre de joueurs, durée des sessions, jeux les plus populaires |
| **Écrans** | Gérer vos écrans/TV connectés |
| **Jeux** | Voir et configurer les jeux disponibles |
| **Membres** | Inviter et gérer les membres de votre équipe |
| **Données utilisateurs** | Configurer la collecte d'emails et de données joueurs |
| **Paramètres** | Modifier votre profil, votre entreprise et la sécurité de votre compte |

## Sélectionner un espace

Si vous gérez plusieurs établissements, sélectionnez l'espace souhaité depuis l'écran d'accueil du dashboard. Chaque établissement a son propre espace avec ses propres statistiques.

## Besoin d'aide ?

Le dashboard inclut un bouton d'aide en bas du menu qui vous redirige vers la FAQ ou vous propose de contacter le support.
