## Format

| | |
|---|---|
| **Durée** | 1h à 1h30 |
| **Jeux utilisés** | Gloofy Pop, Bomber Kitten |
| **Public** | Public jeune, amateurs de compétition |
| **Idéal pour** | Fin de soirée, événements gaming |

## Déroulé recommandé

| Timing | Activité |
|--------|----------|
| **0-5 min** | Connexion et explication |
| **5-25 min** | Gloofy Pop (plusieurs manches) |
| **25-40 min** | Pause (15 min) |
| **40-60 min** | Bomber Kitten (tournoi) |
| **60-75 min** | Pause (15 min) |
| **75-90 min** | Finale : les meilleurs de chaque jeu s'affrontent |

## Gérer les gros groupes (Bomber Kitten)

Bomber Kitten est limité à 20 joueurs. Si vous avez plus de participants :

1. **Formez des groupes** de 10-15 joueurs
2. Chaque groupe joue une manche
3. Les **gagnants de chaque groupe** se retrouvent en finale
4. Le format tournoi crée un suspense naturel et implique tout le monde

<Callout type="tip">
La soirée Arcade est parfaite pour terminer une soirée en beauté. L'énergie et la compétition créent une atmosphère électrique. Montez le son et commentez les éliminations en direct !
</Callout>
