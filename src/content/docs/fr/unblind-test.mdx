## En bref

| | |
|---|---|
| **Catégorie** | Quiz & Culture |
| **Joueurs** | Illimité |
| **Durée** | 3 à 13 minutes |
| **Personnalisable** | Oui (nombre de musiques, thème musical) |

## Le principe

Une musique se lance. Les joueurs doivent reconnaître le titre et l'artiste le plus vite possible en sélectionnant la bonne réponse parmi les propositions affichées sur leur téléphone. Le plus rapide marque le plus de points.

## Déroulement d'une partie

### Configuration

Avant de lancer, choisissez :
- Le **thème musical** : Pop, Rock, Hip Hop, Electro, Chansons Françaises, Années 80, Années 90, Années 2000...
- Le **nombre de musiques** : de 5 à 50 par partie

### Pendant le jeu

![Interface joueur sur téléphone — Unblind Test](/images/screenshots/08a_player-phone-gamepad-unblind-test.jpg)

1. Un extrait musical se lance
2. Les joueurs voient plusieurs propositions sur leur téléphone
3. Ils sélectionnent leur réponse le plus vite possible
4. La bonne réponse s'affiche avec le classement des réponses
5. On passe à la musique suivante

### Fin de partie

Le classement final s'affiche avec les scores de chaque joueur.

## Conseils d'animation

**Au lancement :**
"C'est l'heure du Blind Test ! Une musique se lance, vous devez reconnaître le titre le plus vite possible. Le plus rapide gagne le plus de points !"

**Pendant le jeu :**
- Laissez les joueurs fredonner et chanter : ça crée de l'ambiance
- Commentez les résultats entre chaque morceau
- Variez les réactions : "Celle-là était facile !" ou "Bravo à ceux qui ont trouvé, c'était piège !"

**En cas d'égalité :**
Proposez une manche bonus de 3 musiques entre les ex-aequo.

<Callout type="tip">
Le Blind Test est le jeu le plus populaire en soirée. Il crée une ambiance immédiate, même avec peu de joueurs. Montez le son !
</Callout>

<Callout type="warning">
Après plusieurs parties consécutives, le son peut parfois ne plus se lancer. Si cela arrive, fermez et relancez votre navigateur.
</Callout>
