## Format

| | |
|---|---|
| **Durée** | 1h30 à 2h |
| **Jeux utilisés** | GeoLoc, Unblind Test, Bomber Kitten, P'tit Bac |
| **Public** | Tout public |
| **Idéal pour** | Soirées variées, découverte d'Unboared |

## Déroulé recommandé

Le format idéal : **15 minutes de jeu + 15 minutes de pause**, en boucle.

| Timing | Activité |
|--------|----------|
| **0-15 min** | GeoLoc (3 manches, 3 gagnants) |
| **15-30 min** | Pause |
| **30-45 min** | Unblind Test (15 musiques) |
| **45-60 min** | Pause |
| **60-75 min** | Bomber Kitten (tournoi si +20 joueurs) |
| **75-90 min** | Pause |
| **90-105 min** | P'tit Bac (3 manches) |
| **105-120 min** | Classement final + tournoi des gagnants (bonus) |

## Le tournoi des gagnants (bonus)

À la fin de la soirée, invitez les gagnants de chaque jeu à s'affronter dans un ultime défi. Choisissez un jeu rapide (GeoLoc ou Bomber Kitten) pour une finale spectaculaire.

<Callout type="tip">
Ce format est parfait pour une première soirée Unboared : il fait découvrir tous les types de jeux à votre public et vous permet d'identifier ceux qui fonctionnent le mieux dans votre établissement.
</Callout>
