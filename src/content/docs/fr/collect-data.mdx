---
title: Collecter des données utilisateurs
description: Activez la collecte d'emails et d'informations sur vos joueurs depuis le dashboard.
---

## À quoi ça sert ?

La collecte de données vous permet de récupérer les informations de vos joueurs (email, prénom, téléphone, âge...) pour alimenter votre base de contacts. Vous pouvez ensuite les recontacter pour les inviter à vos prochains événements.

## Activer la collecte

<Steps>
<Step title="Accédez au dashboard">
Rendez-vous sur [b2b.unboared.com](https://b2b.unboared.com) et connectez-vous.
</Step>

<Step title="Ouvrez Données utilisateurs">
Dans le menu de gauche, cliquez sur **Données utilisateurs**.
</Step>

<Step title="Activez la collecte">
Basculez le switch sur **Activée**. Vous pouvez ensuite choisir quelles données collecter.
</Step>
</Steps>

## Données collectables

| Donnée | Description |
|--------|-------------|
| **Email** | L'adresse email du joueur (avec case de consentement newsletter) |
| **Prénom / Nom** | L'identité du joueur |
| **Téléphone** | Le numéro de téléphone |
| **Âge** | L'âge du joueur |

Chaque donnée est activable/désactivable individuellement. Vous ne collectez que ce dont vous avez besoin.

## Ce que voit le joueur

Quand la collecte est activée, les joueurs voient un formulaire supplémentaire lors de leur connexion (après avoir choisi leur pseudo et avatar). Une case de consentement RGPD est affichée pour la collecte d'emails.

## Exporter les données

Les données collectées sont consultables directement dans le dashboard sous forme de tableau. Vous pouvez les exporter en :
- **CSV** : pour importer dans un tableur (Excel, Google Sheets)
- **JSON** : pour intégrer dans un outil technique ou CRM

<Callout type="warning">
La collecte de données personnelles est soumise au RGPD. Assurez-vous de respecter la réglementation en vigueur. La case de consentement affichée aux joueurs vous couvre pour la collecte, mais vous êtes responsable de l'utilisation que vous faites de ces données.
</Callout>

<Callout type="tip">
Commencez par collecter uniquement l'email. C'est le minimum utile pour recontacter vos joueurs, et ça ne rallonge pas trop le processus de connexion.
</Callout>
