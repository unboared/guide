## En bref

| | |
|---|---|
| **Catégorie** | Quiz & Culture |
| **Joueurs** | Illimité |
| **Durée** | 5 à 10 minutes |
| **Personnalisable** | Oui (nombre de manches, temps par manche, catégories) |

## Le principe

Le principe est celui du classique Petit Bac : une lettre est tirée au sort, et les joueurs doivent trouver des mots commençant par cette lettre dans les catégories affichées (ville, animal, métier, etc.). Le tout depuis leur téléphone, avec un temps limité.

## Déroulement d'une partie

### Configuration

Avant de lancer, vous pouvez ajuster :
- Le **nombre de manches**
- Le **temps par manche** (en secondes)
- Les **catégories** utilisées

### Pendant le jeu

![Interface joueur sur téléphone — P'tit Bac](/images/screenshots/08b_player-phone-gamepad-petit-bac.jpg)

1. Une lettre s'affiche à l'écran
2. Les catégories apparaissent sur le téléphone de chaque joueur
3. Les joueurs tapent leurs réponses le plus vite possible
4. Un compte à rebours indique le temps restant
5. À la fin du temps, les réponses sont comparées et les points attribués

### Fin de partie

Le classement final s'affiche. Les joueurs ayant trouvé des mots uniques (que personne d'autre n'a trouvés) marquent des points bonus.

## Conseils d'animation

**Au lancement :**
"C'est le P'tit Bac ! Une lettre va s'afficher et vous devez trouver un mot pour chaque catégorie qui commence par cette lettre. Attention, les réponses originales rapportent plus de points !"

**Pendant le jeu :**
- Commentez les lettres difficiles : "Q ! Bonne chance à tous !"
- Lisez quelques réponses originales à voix haute entre les manches
- Signalez les réponses en double : "4 personnes ont dit la même chose !"

<Callout type="tip">
Le P'tit Bac est un grand classique qui fonctionne avec tout type de public. Il est particulièrement apprécié lors des soirées multigénérationnelles.
</Callout>
