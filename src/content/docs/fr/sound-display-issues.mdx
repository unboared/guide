## Problèmes de son

### Le son ne se lance pas

Les navigateurs modernes bloquent le son automatique tant qu'il n'y a pas eu d'interaction avec la page. **Cliquez une fois** n'importe où dans la page du jeu pour activer le son.

### Le son du Blind Test ne fonctionne plus

Après plusieurs parties consécutives, les musiques peuvent ne plus se lancer alors que le jeu continue visuellement.

**Solution :** Fermez et relancez votre navigateur (pas juste l'onglet, mais tout le navigateur). Les joueurs devront rescanner le QR code.

### Le volume est trop faible

Vérifiez plusieurs niveaux de volume :
1. Le **volume du navigateur** (clic droit sur l'onglet)
2. Le **volume de l'ordinateur**
3. Le **volume de la TV** (si le son passe par le HDMI)
4. Le **volume de l'enceinte externe** (si vous en utilisez une)

<Callout type="tip">
Pour le Blind Test, une enceinte externe est fortement recommandée. Le son de l'ordinateur ou de la TV est rarement suffisant dans un bar.
</Callout>

## Problèmes d'affichage

### L'écran est tronqué ou mal proportionné

Passez en **plein écran** (F11 sur Windows, Fn+F sur Mac). L'affichage d'Unboared est optimisé pour le mode plein écran.

### L'image ne s'affiche pas sur la TV

Vérifiez :
1. Le **câble HDMI** est bien branché des deux côtés
2. La TV est sur la **bonne source** (HDMI 1, HDMI 2...)
3. L'écran de l'ordinateur est bien en mode **duplication** ou **extension**

Sur Windows : `Windows + P` > Dupliquer
Sur Mac : Préférences Système > Moniteurs > Recopie vidéo

### Le QR code est trop petit pour être scanné

Utilisez le **bouton QR Code** dans le panneau de contrôle (en bas à droite) pour afficher le QR code en grand sur tout l'écran.
