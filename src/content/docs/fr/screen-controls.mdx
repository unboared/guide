## Le panneau de contrôle

En bas à droite de l'écran principal, un panneau de contrôle vous donne accès aux commandes essentielles.

![Le panneau de contrôle en bas de l'écran](/images/screenshots/04_settings-buttons-panel.png)

## Les commandes disponibles

| Bouton | Fonction |
|--------|----------|
| **Menu** (icône maison) | Retourner à l'écran de sélection des jeux. Les joueurs restent connectés : pas besoin de rescanner. La partie en cours s'arrête. |
| **Pause / Reprendre** | Mettre le jeu en pause ou le reprendre. Utile pour faire une annonce ou gérer un imprévu. Dans le Blind Test, la pause arrête le chrono mais pas la musique : coupez aussi le son si besoin. Quand vous pilotez depuis votre téléphone, ce bouton passe sur la télécommande. |
| **QR Code** | Afficher le QR code en grand sur tout l'écran. Le jeu se met automatiquement en pause. Fermez pour reprendre. |

Le bouton à trois traits (☰), à droite des autres, regroupe le reste :

| Bouton | Fonction |
|--------|----------|
| **Plein écran** | Passer en mode plein écran ou en sortir. Équivalent de F11. |
| **Couper le son** | Couper ou remettre le son du jeu. Utile si vous faites une annonce au micro. |
| **Supprimer les scores** | Supprimer définitivement les scores de ce jeu pour votre établissement (une confirmation est demandée). |

## Quand utiliser quoi

### Afficher le QR code en grand

Utilisez cette fonction quand vous voulez **inviter de nouveaux joueurs** à rejoindre. Le QR code s'affiche en grand sur tout l'écran, ce qui le rend plus facile à scanner de loin.

Le jeu se met automatiquement en pause quand le QR code est affiché, et reprend quand vous le fermez.

![Le QR code affiché en grand sur tout l'écran](/images/screenshots/05_big-qr-code.png)

### Mettre en pause

La pause est utile pour :
- Faire une **annonce** au public
- Gérer un **imprévu** technique
- Laisser le temps aux joueurs de **se reconnecter**

### Couper le son

Utile quand :
- Vous prenez le **micro** pour une annonce
- Le son du jeu gêne une conversation importante
- Vous faites une **pause musicale** entre deux jeux

## La télécommande sur votre téléphone

Vous pouvez piloter la soirée depuis votre propre téléphone, sans retourner à l'ordinateur. Sur le menu de la TV, la carte **« Pilote depuis ton téléphone »** (ou, une fois la carte fermée, le badge **« Piloter depuis le téléphone »**) affiche un QR code : scannez-le avec votre téléphone.

Depuis la télécommande, vous pouvez :
- **Choisir ou changer de jeu**, puis le lancer ou l'arrêter
- **Mettre en pause** et **couper le son**
- **Afficher le QR code** des joueurs en grand sur la TV
- Voir le **nombre de joueurs connectés**
- Régler la partie selon le jeu (par exemple la playlist du Blind Test ou la régie du quiz)

<Callout type="tip">
Prenez quelques minutes pour vous familiariser avec ces contrôles avant votre première animation. Ça vous évitera de chercher pendant l'événement.
</Callout>
