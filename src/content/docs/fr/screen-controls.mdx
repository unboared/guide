## Le panneau de contrôle

En bas à droite de l'écran principal, un panneau de contrôle vous donne accès aux commandes essentielles.

![Le panneau de contrôle en bas de l'écran](/images/screenshots/04_settings-buttons-panel.png)

## Les commandes disponibles

| Bouton | Fonction |
|--------|----------|
| **Accueil** (icône maison) | Retourner à l'écran de sélection des jeux. Les joueurs devront rescanner le QR code. |
| **Pause / Reprendre** | Mettre le jeu en pause ou le reprendre. Utile pour faire une annonce ou gérer un imprévu. |
| **QR Code** | Afficher le QR code en grand sur tout l'écran. Le jeu se met automatiquement en pause. Fermez pour reprendre. |
| **Plein écran** | Passer en mode plein écran ou en sortir. Équivalent de F11. |
| **Couper le son** | Couper ou remettre le son du jeu. Utile si vous faites une annonce au micro. |

## Quand utiliser quoi

### Afficher le QR code en grand

Utilisez cette fonction quand vous voulez **inviter de nouveaux joueurs** à rejoindre. Le QR code s'affiche en grand sur tout l'écran, ce qui le rend plus facile à scanner de loin.

Le jeu se met automatiquement en pause quand le QR code est affiché, et reprend quand vous le fermez.

![Le QR code affiché en grand sur tout l'écran](/images/screenshots/05_big-qr-code.png)

### Mettre en pause

La pause est utile pour :
- Faire une **annonce** au public
- Gérer un **imprévu** technique
- Laisser le temps aux joueurs de **se reconnecter**

### Couper le son

Utile quand :
- Vous prenez le **micro** pour une annonce
- Le son du jeu gêne une conversation importante
- Vous faites une **pause musicale** entre deux jeux

<Callout type="tip">
Prenez quelques minutes pour vous familiariser avec ces contrôles avant votre première animation. Ça vous évitera de chercher pendant l'événement.
</Callout>
