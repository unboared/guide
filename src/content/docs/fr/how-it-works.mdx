## Le principe

Unboared est une solution de jeux interactifs pour les lieux qui accueillent du public : bars, restaurants, hôtels, campings, espaces de coworking, événements...

Le concept est simple :

1. **Vous branchez un ordinateur à une TV** via un câble HDMI
2. **Vous ouvrez Unboared** dans votre navigateur
3. **Vos clients scannent un QR code** affiché sur la TV
4. **Ils jouent directement depuis leur téléphone** — sans rien télécharger

Le téléphone devient la manette. La TV affiche le jeu. Tout passe par le navigateur web.

![Unboared en situation dans un bar](/images/screenshots/09_physical-setup.jpg)

## Comment les joueurs rejoignent

Un QR code est toujours visible sur l'écran principal. Les joueurs le scannent avec l'appareil photo de leur téléphone, choisissent un pseudo et un avatar, puis rejoignent la partie en un clic.

Aucune application à installer, aucun compte à créer côté joueur. Ça fonctionne sur tous les smartphones, Android comme iPhone.

## Ce que vous contrôlez

En tant qu'animateur, vous gardez le contrôle depuis votre ordinateur :

- **Choisir le jeu** parmi le catalogue
- **Lancer et mettre en pause** les parties
- **Afficher le QR code** en grand pour inviter les joueurs
- **Suivre les scores** en temps réel sur la TV

## Ce que vos clients voient

Sur la TV, l'écran se divise en trois zones :
- Le QR code et les instructions pour rejoindre **à gauche**
- Le jeu en cours **au centre**
- Les meilleurs scores **à droite**

![L'écran de jeu avec les 3 zones : QR code, jeu et scores](/images/screenshots/02_game-screen-3-columns.png)

Sur leur téléphone, l'interface s'adapte à chaque jeu (buzzer, choix multiples, joystick...) :
